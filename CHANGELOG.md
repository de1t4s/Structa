# Changelog

All notable public Structa releases are documented here.

Structa uses a `MAJOR.MINOR.PATCH` versioning scheme for published builds.

## [1.3] - 2026-10-02

### Public distribution

- Established the official public GitHub distribution repository for Structa.
- Prepared the repository for Android APK releases.
- Added public documentation, branding, screenshots, privacy information and security guidance.
- Documented the current Structa workflow: document scanning, OCR, file organization, editing/export and Ask Structa.

### Download

The Android APK is distributed through the repository's **GitHub Releases** page and is not committed to the source tree.

> Application source code, backend code and development/debug material are maintained privately.
