# Structa v1.3 — Your documents, understood.

Structa v1.3 is the first build published through the new official public distribution repository.

## Highlights

- Scan documents from your Android device.
- Extract useful text with OCR.
- Organize documents in the Structa library.
- Edit, annotate, convert and share documents.
- Ask Structa questions about your documents and receive grounded answers with source references in the experience.

## Download

Attach the following file to the GitHub Release:

`structa-1.3.apk`

## Requirements

- Android 7.0 (API 24) or newer.
- Internet connection for Ask Structa and other network-backed functionality.

## Installation

1. Download `structa-1.3.apk` from the release Assets.
2. Allow installation from your browser or file manager if Android asks.
3. Open the APK and follow Android's installation prompt.

Android may display a warning because the APK is installed outside an app store. Make sure the file comes from the official Structa repository and verify the checksum above when possible.
