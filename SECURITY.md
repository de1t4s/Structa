# Security Policy

## Official downloads

Only download Structa APKs from the **Releases** section of this repository:

https://github.com/de1t4s/Structa/releases

Do not install APKs claiming to be Structa from unofficial mirrors unless you independently trust and verify them.

When a release includes a SHA-256 checksum, compare it with your downloaded file before installation.

## Supported releases

| Version | Status |
| --- | --- |
| 1.3.x | Current public release line |
| Older builds | Not guaranteed |

Security fixes, when needed, are expected to ship in the newest available release.

## Reporting a vulnerability

Please **do not open a public Issue** for a vulnerability that could expose user data, credentials, private documents, authentication flows, backend infrastructure or other sensitive information.

Use GitHub's private vulnerability reporting / Security Advisory flow for this repository if it is available. If that option is unavailable, contact the maintainer privately through the GitHub account **@de1t4s** before publishing technical details.

A useful report includes:

- affected Structa version;
- Android version/device;
- steps to reproduce;
- impact;
- proof of concept, if safe to share privately;
- any suggested mitigation.

Please remove real personal documents, secrets, tokens and credentials from reports.

## Scope

This repository is a public distribution repository. Structa's application source code, backend source code and development infrastructure are maintained separately and are not published here.
