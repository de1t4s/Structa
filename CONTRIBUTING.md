# Contributing to Structa

Thanks for helping improve Structa.

This repository is primarily the **public distribution and documentation hub** for the Android app. The application and backend source code are currently private, so source-code contributions to the app cannot be accepted through this repository.

## Report a bug

Open a Bug Report and include:

- Structa version;
- Android version and device model;
- clear steps to reproduce;
- expected behavior;
- actual behavior;
- screenshots or logs only after removing sensitive information.

Please do **not** attach real private documents unless they are fully anonymized.

## Request a feature

Open a Feature Request and explain:

- the problem you are trying to solve;
- the workflow you expect;
- why it would be useful;
- any relevant examples.

## Documentation

Small improvements to public documentation, wording and repository presentation are welcome.

## Security issues

Do not disclose vulnerabilities in public Issues. Follow [SECURITY.md](SECURITY.md).

## Conduct

Keep discussions constructive, specific and respectful. Avoid posting personal data, credentials, private documents or unrelated promotional content.
